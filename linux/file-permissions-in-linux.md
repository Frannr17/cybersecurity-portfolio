# File Permissions in Linux

## Overview

This project demonstrates how Linux file and directory permissions can be inspected, interpreted, and modified using standard command-line utilities. It focuses on implementing secure access control by applying Linux permission management and the Principle of Least Privilege.

## Project Description

In this project, I explored the Linux permission model by inspecting file and directory permissions, interpreting permission strings, and modifying permissions using the `chmod` command. The exercises covered both regular and hidden files, reinforcing the importance of correctly assigning permissions to protect sensitive resources.

---

## Objectives

- Inspect Linux files and directories.
- Understand Linux permission strings.
- Modify file permissions securely.
- Apply permissions to hidden files.
- Manage directory permissions.

---

## Methodology

The project was completed using standard Linux shell commands. File permissions were analyzed with `ls -l` and `ls -la`, while permission changes were performed using symbolic mode with the `chmod` command. The exercises demonstrated how read, write, and execute permissions affect different user groups.

---

## Results

Successfully identified and modified Linux file permissions while maintaining secure access controls. Demonstrated an understanding of how Linux authorization mechanisms protect files and directories from unauthorized access.

---

## Key Takeaways

Proper permission management is one of the fundamental security controls in Linux systems. Applying the Principle of Least Privilege significantly reduces the attack surface and minimizes the impact of unauthorized access.
