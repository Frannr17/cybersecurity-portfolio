# Data Leak Worksheet

## Overview

This project analyzes a data leakage incident caused by excessive permissions and improper access management. It evaluates how the Principle of Least Privilege could have prevented the exposure of sensitive organizational information.

- Principle of Least Privilege

---

## Project Description

This project investigates a data leak resulting from excessive access permissions and accidental file sharing. The analysis identifies the root cause of the incident and recommends controls to reduce the likelihood of future data exposure.

---

## Objectives

- Identify contributing factors.
- Evaluate existing access controls.
- Apply NIST guidance.
- Recommend preventive measures.

---

## Methodology

The incident was reviewed from an access control perspective using NIST SP 800-53 AC-6. Existing permissions were evaluated and compared against least privilege principles to identify security improvements.

---

## Results

The analysis concluded that excessive permissions significantly contributed to the incident. Recommendations included role-based access control, automatic permission revocation, activity logging, and periodic privilege reviews.

---

## Key Takeaways

Restricting access to only the resources required for each role is one of the most effective methods of preventing accidental or intentional data leaks.
