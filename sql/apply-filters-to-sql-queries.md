# Apply Filters to SQL Queries

## Overview

This project demonstrates how SQL queries and filtering techniques can be used to investigate security events, analyze login activity, and identify specific employee groups for administrative tasks. By combining filtering operators such as `WHERE`, `AND`, `OR`, `LIKE`, and `NOT`, the project retrieves precise information from organizational databases to support security investigations and system administration.

## Project Description

This project consists of multiple SQL queries designed to retrieve relevant information from organizational databases during security investigations and administrative operations. Different filtering techniques are applied to identify failed login attempts, suspicious geographic activity, and employee groups requiring system updates. The project demonstrates how SQL can efficiently support security operations by extracting only the data relevant to a particular investigation.

---

## Objectives

- Retrieve failed login attempts after business hours.
- Identify login attempts during specific dates.
- Detect login attempts originating outside the organization's country.
- Locate employee groups for scheduled system updates.
- Demonstrate efficient SQL filtering techniques.

---

## Methodology

Several SQL queries were developed using filtering operators including `WHERE`, `AND`, `OR`, `LIKE`, and `NOT`. Each query targeted a different business or security scenario, allowing only the required records to be returned while minimizing unnecessary data retrieval.

---

## Results

The SQL queries successfully isolated relevant security events and employee records for investigation and administrative purposes. Each query returned only the information required for its specific objective, demonstrating the effectiveness of SQL filtering in cybersecurity operations.

---

## Key Takeaways

SQL is one of the most valuable skills for cybersecurity professionals. Efficient query development enables analysts to investigate security events, analyze authentication logs, and retrieve critical information quickly while minimizing unnecessary data processing.
